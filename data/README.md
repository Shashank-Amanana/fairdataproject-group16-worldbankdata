This directory contains the original and the FAIRified dataset.

| Folder | Content |
|---|---|
| `original/` | Original data (CSV) |
| `clean/` | Prepared data (CSV), as produced by the OpenRefine operations before splitting |
| `openrefine/` | OpenRefine project (import it with "Import project") and its operations (`openrefine-operations.json`), which turn the original CSV into the RDF |
| `rdf/` | FAIRified data (RDF, in Turtle and RDF/XML) |
