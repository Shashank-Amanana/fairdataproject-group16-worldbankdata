This directory contains the original and the FAIRified dataset.

| Folder | Content |
|---|---|
| `original/` | Original data (CSV) |
| `clean/` | Prepared data (CSV), used as input for OpenRefine |
| `openrefine/` | OpenRefine project (import it in OpenRefine with "Import project") |
| `rdf/` | FAIRified data (RDF, in Turtle and RDF/XML) |
